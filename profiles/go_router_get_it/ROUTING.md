# Routing: go_router + go_router_builder

- Use typed `go_router` routes generated by `go_router_builder`; do not add parallel imperative route registries.
- Put route declarations and generated route integration in the profile-selected routing location.
- Navigation returns typed results when the originating screen must refresh state. The destination performs its mutation, pops a result from a listener, and the origin refreshes its own Cubit after awaiting the result.
- Never navigate directly from a Cubit.
